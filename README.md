# 🏆 BracketFlow - Tournament Manager

O **BracketFlow** é uma ferramenta minimalista e poderosa para criação e gerenciamento de chaves de torneios em tempo real. Com uma interface focada em alta performance e design monocromático (Preto, Cinza e Branco), o sistema permite que organizadores gerenciem competições de forma intuitiva.

---

## 🎨 Preview do Design
* **Tema:** Monocromático de Alto Contraste.
* **Interface:** Sidebar de gerenciamento com Viewport de visualização dinâmica.
* **Estética:** Grid de engenharia e tipografia sans-serif moderna.

---

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estrutura semântica para chaves de competição.
* **CSS3:** Layout flexbox e grid com design responsivo e efeitos de transição.
* **JavaScript (Vanilla):** Motor de lógica para atualização em tempo real e promoção de competidores.

---

## 🚀 Como Rodar o Projeto
1. Certifique-se de que os três arquivos (`index.html`, `style.css` e `script.js`) estão na mesma pasta.
2. Abra o arquivo `index.html` em qualquer navegador moderno.
3. Insira os nomes nos **Slots** laterais.
4. Clique nos cards da chave para avançar os vencedores até a final.
